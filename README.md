# CatatUang PWA

Web app pencatatan keuangan harian yang responsive untuk iOS dan Android.

## Menjalankan
- Untuk fitur PWA/offline, gunakan HTTPS hosting atau localhost.
- Upload semua file ke hosting dalam satu folder.
- Buka URL dari Safari (iPhone) atau Chrome (Android).
- iPhone: Share -> Add to Home Screen.
- Android: menu browser -> Install app / Add to Home screen.

Data transaksi disimpan di localStorage perangkat/browser. Export CSV tersedia dari menu Export.

## File
index.html, style.css, app.js, manifest.json, sw.js, icon.svg
